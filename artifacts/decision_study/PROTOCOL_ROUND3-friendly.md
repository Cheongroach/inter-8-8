# 第三轮协议：哪些方法真正用了银行业务标签

冻结日期：2026-10-25。[原协议](PROTOCOL_ROUND3.md)保留不动，实际结果见[图解报告](REPORT_BANKING77-friendly.md)。

前两轮只调整新闻分类的输出概率。第三轮改用 Banking77，问“候选表示预算”和“领域监督”能否改善 77 类业务决策。监督头会看银行训练标签，所以不能与无本轮领域训练的 Laya 直接做零样本公平排名。

## 先划分，再学参数

源固定为 PolyAI-LDN/task-specific-datasets 提交 `57ec275d8078af65b7731c2a98be812d844a6d6b` 的 `banking_data/`，检查 train / test / categories 的 Git blob，保留原行号与规范化文本 SHA256。

训练源优先做精确文本去重，跨训练 / 测试重复的测试行删除。每个训练类别按 `SHA256("banking77-r3:" + id)` 排序，前 10 条验证，其余拟合。官方测试剩余数据在验证选择锁写入后才评价；测试不参与词表、IDF、分类头、温度和任何超参数选择。

上游脚本把 Banking77 标为非训练内任务，但本项目没有独立审计其所有预训练数据。精确去重也不能去掉所有近义表达。

## 六组候选分别隔离什么

| 候选 | 固定设置 | 要隔离的问题 |
|---|---|---|
| 原 Laya | `max_len=512, head_max_len=192` | 原权重直接处理 77 类 |
| 扩大预算 | `max_len=1024, head_max_len=768` | 保持权重，增加描述空间 |
| 词法头 | word(1,2)＋char_wb(3,5) TF-IDF；各最多 50,000 特征，min_df=2，sublinear_tf，拼接后 L2 归一化；逻辑回归 C=1/4/16 | 简单领域监督能做到多少 |
| 稠密头 | 上游 `embed_fn_from_agent` mean pooling，max_length=128，L2 归一化；逻辑回归 C=1/10/100 | 冻结 Encoder 表征的领域分类能力 |
| 概率混合 | 稠密权重 0 / 0.25 / 0.5 / 0.75 / 1 | 两种表征能否互补 |
| top-10 重排 | 监督验证赢家筛候选；按原类顺序送给 Laya；max_len=512，head_max_len=256 | 候选缩小后能否正确重排 |

C 是正则强度倒数。稠密头只训练新的线性分类器，不更新原 Encoder 或 typed head。mean pooling 和候选筛选都复用上游已有能力，本项目不把它们称为新算法。

top-10 不允许根据 gold label 强插候选。除纯重排外，还比较 \(\log p_{\mathrm{classifier}}+\alpha z/T_{10}\)，α=0.25 / 1；候选外概率置零，漏召回按系统错误计。

每层都依次按验证准确率、NLL、固定名称选优。最终从原模型、扩大预算、监督赢家和三种重排方案中选择，参数与选择写入不可覆盖文件后才评价测试。所有注册最终候选披露，不能看完测试换赢家。

## 为什么还要保存完整概率

准确率可能变好而概率变差。完整 77 类概率允许独立复算 NLL、Brier、ECE，检查 top-10 外的零概率惩罚。[指标说明](../METRICS.md)给出具体公式。

同时报告 top-10 recall、输入截断、不同类别是否变成相同 token 表示；准确率配对 bootstrap 2,000 次、seed 20261025。保存输入 ID、标签、候选、logits / 概率、数据 / 代码指纹和新分类头参数。

各阶段分开计时，CPU FP32、8 线程，包含对应的编码 / 决策或拟合成本。离线 batch 时间不能写成服务 P95 / P99，也不能跨硬件推导速度。

## 这套实验允许什么结论

可以回答固定 Banking77 schema、一次数据划分、固定 Encoder 下哪些候选更好，能否加载保存参数。不能回答多语言、新工具、任意 schema、真实业务拒答、完整领域微调模型的能力或 SOTA。

实际划分为拟合 9,229、验证 770、测试 3,072；这是执行结果，原协议先规定规则。复现与加载见[操作说明](BANKING77_REPRODUCE.md)，验证选择见[selection.json](results_round3/selection.json)，完整样本见[protocol.json](results_round3/protocol.json)。

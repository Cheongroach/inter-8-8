# Jev / Laya：三轮质量实验说明

数据截至 2026-10-25；阅读版本整理于 2026-10-26。

Laya 已完成三轮真实权重实验。当前最明确的准确率结果来自 Banking77：在 3,072 条银行业务测试输入上，监督融合为 91.67%，词法监督基线为 90.82%，净多答对 26 条。不过融合的概率评分更差。Jev 没有 API 凭据，本轮实际调用为 0；现有证据还不能建立 SOTA，即同条件下的最先进水平。

## 要判断什么

决策模型从给定选项中选择答案，例如新闻的四种类别或银行业务的 77 种意图。我们分别检查“选项有没有选对”和“给正确答案的概率是否合理”。准确率回答前者；NLL、Brier、ECE 回答概率评分或校准问题，都是越低越好。定义与小例子见[指标说明](../METRICS.md)。

三轮每次都先拟合参数，再用验证集选择配置，最后才评价保留测试集。拟合集学参数，验证集选方法，保留集最终评分；不能按测试改选赢家。

| 轮次 | 问题与数据：拟合 / 验证 / 测试 | 验证集选出的方案 | 保留集结果 |
|---|---|---|---|
| 第一轮 | 小数据新闻校准；128 / 128 / 256 | 20 参数仿射校准 `affine_1.0` | 准确率 93.36% → 93.75%，差值区间跨零；NLL 退化 |
| 第二轮 | 目标分布新闻校准；1,024 / 512 / 512 | 温度 1.582823 | 准确率仍为 93.75%，NLL 0.1803 → 0.1746；Brier 略差 |
| 第三轮 | 银行业务细粒度分类；9,229 / 770 / 3,072 | 75% 词法＋25% 冻结 Encoder 分类头概率 | 准确率 91.67%，比词法基线高 0.85 pp；概率指标退化 |

三轮任务和数据不同，不能合并成一个模型总分。它们也与 Qwen 的 H20 / 910B4 训练计时分开评价。

## 最新的领域分类结果

![Banking77 实测准确率与配对差值](../figures/banking77-friendly.png)

图中监督方案用了领域训练标签。左图展示选对多少；右图比较同一条测试输入上的融合与词法基线，横线是配对样本 bootstrap 区间，不是训练种子波动。

TF-IDF 用词或字符片段在文本及语料中的出现频率构造特征。“词法分类器”把词和字符片段变成这些特征，再训练线性分类头。“稠密分类器”让冻结的 Laya Encoder 把文本变成向量，再训练新的线性头。融合把两个完整类别概率相加：

\[
p_{\mathrm{mix}}(k)=0.75p_{\mathrm{lexical}}(k)+0.25p_{\mathrm{dense}}(k).
\]

两个头均使用 9,229 条银行业务标签，原 Laya Encoder 与原 typed decision head 没有更新。验证集选定词法正则参数 C16、稠密 C100，再选稠密权重 0.25。

| 方法 | 测试准确率 | NLL ↓ | Brier 求和 ↓ | ECE15 ↓ |
|---|---:|---:|---:|---:|
| Laya 默认 77 类 | 45.08% | 4.3379 | 0.8832 | 0.3537 |
| Laya 扩大候选预算 | 57.00% | 3.2423 | 0.7077 | 0.2743 |
| 词法监督分类器 | 90.82% | 0.4145 | 0.1564 | 0.1026 |
| 冻结 Laya Encoder＋分类头 | 82.42% | 0.7610 | 0.2922 | 0.1519 |
| 监督概率融合（验证选定） | 91.67% | 0.4438 | 0.1639 | 0.1550 |
| 监督 top-10＋Laya 纯重排 | 67.25% | 1.3474 | 0.4891 | 0.1414 |
| top-10＋分类器先验，α=0.25 | 91.57% | 0.3775 | 0.1316 | 0.0462 |
| top-10＋分类器先验，α=1 | 83.59% | 0.6881 | 0.2525 | 0.0828 |

融合对词法基线为 44 胜、18 负：净增 26 条正确结果，准确率差为 +0.8464 pp，2,000 次配对 bootstrap 的 95% 区间为 [+0.3581,+1.3346] pp。它支持本次固定测试集上的准确率改善，未覆盖重新训练、重新划分和未来分布。

默认选项预算让 77 类只剩 73 种不同 token 表示；扩大预算恢复 77 种，准确率提高但仍低于监督基线。监督前十候选的正确答案召回率为 99.71%，纯 Laya 重排却只有 67.25% 准确率。这说明本轮还存在“候选已包含正确答案，重排仍选错”的问题。

弱先验 α=0.25 在测试概率指标上较好，但验证集没有选中。它保留披露，不能看完测试后替换原赢家。全部诊断、错误类别、计时与重排公式见[Banking77 详细说明](REPORT_BANKING77-friendly.md)。

## 第二轮为什么值得保留

新闻分类只有四类。第二轮问的是“让概率更合理，能否保持选择不变”，而不是重新训练主干。

温度缩放用 \(p_k=\mathrm{softmax}(z_k/T)\)。正温度改变概率尖锐程度，不改变最大分数位置，所以选项可以完全一致而 NLL 改善。本轮用验证集选温度 1.582823071997706。

第二轮从官方 7,600 条测试源中的未用样本划出 1,024 条拟合、512 条验证、512 条新保留集，先排除第一轮已看过的 256 条。三组互斥。这是自定义目标分布校准，不能称 AG News 官方完整测试集成绩；上游还将 AG News 标为训练内任务，不能称领域外泛化。

| 配置 | 新保留集准确率 | NLL ↓ | Brier 求和 ↓ | ECE15 ↓ |
|---|---:|---:|---:|---:|
| checkpoint 自带温度 | 93.75% | 0.1803 | 0.0926 | 0.0334 |
| 新拟合温度（验证选定） | 93.75% | 0.1746 | 0.0927 | 0.0235 |
| 仿射校准 0.1 | 94.14% | 0.1768 | 0.0934 | 0.0267 |
| 仿射校准 1.0 | 93.95% | 0.1792 | 0.0926 | 0.0313 |
| 仿射校准 10.0 | 93.55% | 0.1802 | 0.0925 | 0.0268 |

选定温度与基线的选择完全一致，0 胜 / 0 负。逐条 NLL 差值取“候选减基线”，均值 -0.00572，配对 95% 区间 [-0.00958,-0.00128]；区间低于零，支持本轮 NLL 改善。Brier 精确值从 0.09256145 变为 0.09268819，不能称全部概率指标改善。

第二轮同时增加数据、改变校准来源、修正仿射先验并改变选优目标，所以不能单独认定哪项造成改善。具体规则见[第二轮协议说明](PROTOCOL_ROUND2-friendly.md)。

## 第一轮为什么没有推广

第一轮使用完整 AG News 测试源，但训练下载截断；在任何预测前固定仅用训练源前 20,000 条完整行。按 ID 哈希取 128 条拟合、128 条验证、256 条测试，并移除跨集合规范化全文重复。

每条输入运行四种循环选项排列，再把分数恢复到原类别位置。仿射校准是对四类分数做 \(Az+b\)，其中 \(A\) 为 4×4 矩阵，\(b\) 有 4 个元素，共 20 个参数；没有更新 Encoder。

| 配置 | 保留集准确率 | NLL ↓ | Brier 求和 ↓ | ECE15 ↓ |
|---|---:|---:|---:|---:|
| checkpoint 自带温度 | 93.36% | 0.2117 | 0.1038 | 0.0236 |
| 新拟合温度 | 93.36% | 0.2541 | 0.1100 | 0.0497 |
| 仿射 0.01 | 93.36% | 0.3132 | 0.1225 | 0.0582 |
| 仿射 0.1 | 93.75% | 0.2745 | 0.1178 | 0.0578 |
| 仿射 1.0（验证选定） | 93.75% | 0.2568 | 0.1115 | 0.0501 |
| 四排列集成 / 自带温度 | 94.14% | 0.2107 | 0.1022 | 0.0246 |
| 四排列集成 / 新温度 | 94.14% | 0.2527 | 0.1066 | 0.0470 |

选定方案只有 2 胜 / 1 负，准确率差 +0.39 pp，95% 区间 [-0.78,+1.56] pp，且 NLL 与 Brier 退化。四排列集成在测试上较好，但验证未选中，也不能事后改选。

原顺序与循环移位两位的答案翻转率为 0.78%，只覆盖这种排列测试，不能证明任意排列不变。全部候选和选择规则见[第一轮协议说明](PROTOCOL-friendly.md)。

第一轮四排列执行共 341.85 秒；第二轮 2,048 条输入执行 299.29 秒。都是 CPU eager（直接执行 PyTorch 算子）、8 线程、batch 8，含分词、forward 与解码，排除模型加载；第二轮为 FP32。第一轮 256 条、第二轮 512 条保留集均无报告的输入截断。这些离线时间不等于服务 P95 / P99，也不能直接比较 Jev 托管 API。

19 项数值、候选映射和响应契约测试通过。第二轮 8 例回放选择一致，最大概率差 0.00004689；第三轮 16 例公共 API 回放选择一致，最大概率差低于 3.3e-6。回放验证保存参数与推理路径一致，不增加质量样本数。Banking77 初次内部推理缺少 inference context 的中断和恢复过程保留在[原报告](REPORT_BANKING77.md)。

## 尚未回答的问题

当前没有 Jev 的真实 API 对照，也没有强全参数微调分类器、生成模型首 token 决策和 Laya 领域微调 checkpoint 的同协议比较。单一新闻 / 银行业务实验不能覆盖工具选择、多语言、RAG 门控、新 schema、拒答阈值和真实服务成本。

精确文本去重不能去掉所有语义相近样本或新闻同事件相关性；案例重采样区间没有覆盖训练随机性。正式推广还需要独立领域、按事件 / 时间 / 来源分组的验证、多训练种子和真实服务负载。

原 NPU×16 与新版混合 8＋8 任务已于 10 月 25 日确认 `stopped/killed`，见[终态说明](../16card-experiments/cancellation-20261025-friendly.md)。取消的是训练系统实验臂；它们没有提供 Jev / Laya 决策能力证据。

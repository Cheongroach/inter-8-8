# 原项目方案：训练系统每一层准备解决什么

这是[原方案](proposal.md)的阅读版本。它包含曾计划但未验收的模块；当前选择以[实测结论](experiment-conclusions-friendly.md)为准，不能把方案清单写成成果。

原目标是在已有 Qwen3 主干上训练决策 head，直接输出 Choice、Noul、Score，再比较 CUDA / NPU 与低带宽同步。主指标是达到同一决策与概率质量所需时间，而不是单步速度。

## 从一条输入到一个决策

第一版输入为 `state → question instructions → options → read marker`。state 是当前案例文本，options 是允许的候选，read marker 是指定读输出的位置。

Qwen causal 主干在最后有效 marker 输出 hidden state，小型 code head 给出类别分数，只对真实的 K 个 code 做 softmax，再映射回请求 option ID。padding 不参与概率或 loss。code 顺序和业务选项顺序不能混淆。

第二版考虑多问题共享主干，目的是减少重复计算；它不是原 Laya 的等价替换，需要定义问题独立性、位置、mask 和新训练目标。每题 / 每案例 / 每 token 的损失分母见[训练说明](research-friendly.md)。

## 模块之间怎样分工

| 模块 | 职责 | 正确性边界 |
|---|---|---|
| Model adapter | 加载主干和新 head | 实际训练参数、read position、有效类别 |
| Batch planner | 分桶、任务混合、rank 分配与累积 | 不漏 / 重样本，案例权重一致 |
| Loss contract | 保存 sum 与有效权重，全局归一化 | 不直接平均负载不同的局部 mean |
| Island trainer | 机内 FSDP2、精度、重计算、optimizer | 初始化峰值、更新与 clipping |
| Outer optimizer | 局部训练后的参数 / delta 聚合 | base version、外部动量、组间权重 |
| Transport | 分块、校验、重试和完成确认 | 不混参数区间，不重复聚合 |
| Checkpoint | 权重、优化器、随机数状态、数据计划、外部状态 | 恢复同一个完整轮次 |
| Evaluator | 质量、校准、时间与费用 | 固定保留集和质量门槛 |

“岛”是内部通信较快、独立进行分片训练的一组设备。同步 HSDP 每次更新跨岛同步梯度；Local SGD 每 H 步平均模型；DiLoCo 还有外部 optimizer；压缩再加入数值近似。后三者需要独立质量验收，不能声称等价全局 AdamW。

## 最关键的恢复场景

两组从同一版本开始，一组只发送部分更新就掉线。系统要知道这轮是否完整提交，重传是否重复，模型是否匹配 optimizer / 随机数状态 / 数据游标。

第一版建议所有参与组退回最后完整轮次，重放未提交工作。若支持剩余组继续运行、旧组重新加入，需要成员版本、聚合权重和 防止旧成员提交过期更新的规则；不能默认为原同步算法。这是拟实现场景，本项目没有故障注入恢复验收。

## 为什么原计划分阶段

| 阶段 | 用什么负载 | 应拿到的证据 |
|---|---|---|
| 环境 / 通信 | 每类 1–2 卡 | 实际节点、版本、聚合和写回 |
| 小模型正确性 | Laya 322M / 421M 或缩小配置 | mask、loss、梯度、更新、恢复 |
| 8B 主训练 | 单岛 4 / 8 卡 | 可用权重、质量、单岛 profile |
| 低通信对照 | 同构双岛 8 / 16 卡 | 质量时间、流量、同步 / Local SGD / DiLoCo |
| 14B / 32B 扩展 | 更大参数与状态 | 初始化、长序列、分片、恢复边界 |
| 结构扩展 | joint head / 多模态 | 在已验证基线上的独立贡献 |

8.2B / 14.8B / 32.8B 是原 Qwen3 模型卡参考参数数，改 head 后必须重新统计。基础状态 \(16P\) 字节不包含激活与临时物化，不能只数 BF16 权重就判断容量。

原候选数据为 MASSIVE 意图分类、HelpSteer2 多维评分、ContractNLI 长文判断。它们用于方案负载设计，不是本项目已经完成的训练数据；实际系统预验使用 GSM8K，实际决策实验使用 AG News / Banking77。

## 原门槛与当前结果

方案要求先固定数据 / schema / 质量门槛，给同步与低通信相同调参预算，再比较最慢 rank 墙钟、有效 token、传输、内存和恢复。费用需实际单价，排队时间单独报告。

后续通信可行性、历史全参数 CE 和 H20×16 计时已经完成，但没有证明原 8B–32B 决策模型完整训练与恢复路线达标；新版两个缺失实验臂已取消。当前实际质量成果是[三轮决策实验](decision_study/REPORT.md)。完整 loss、后端接口、验收门槛和原计划参数见[技术原稿](proposal.md)。
